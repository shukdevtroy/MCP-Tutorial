# Project Ideas

## MCP Knowledge Base Chatbot
Internal codename: **Project Nightjar**.
Goal: build a Gradio chatbot that answers questions using local markdown
notes, via an MCP server exposing search_notes and read_note tools.
Target free model: a tool-calling-capable model on OpenRouter.

## Bangla Sentiment Classifier v2
Plan to retrain the Bangla sentiment classifier using a new dataset of
14,200 labeled social media comments. Target macro-F1: 0.87.

## Face Recognition Liveness Check
Add an anti-spoofing step (blink detection + texture analysis) before the
face recognition pipeline accepts a match.
